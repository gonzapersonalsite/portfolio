# Plan de herramienta (el trabajo que no es del producto)

**Qué planifica:** el andamio con el que se construye el producto — el
contrato, las puertas, los arneses, el tablero y la gobernanza de los
documentos. **No planifica nada que el usuario vaya a ver**: eso es `ROADMAP.md`,
y esa frontera es la regla dura 5 de `../AGENTS.md`.

## Cómo leer este plan

- **Un tramo entrega una propiedad del andamio**, no una tarea suelta: algo que
  antes no se podía garantizar y después sí, verificado por una puerta.
- **Los números son IDENTIDAD, no secuencia.** El orden de trabajo, en una línea:

  **H0 ✔ → H1 ✔**

- **La línea, las cabeceras y las partes siguen las reglas de `ROADMAP.md`:**
  qué puede nombrar la línea, quién decide las partes, quién las marca DONE y
  dónde va el porqué de cada cifra.
- **Este plan cede el paso.** Ningún tramo interrumpe una fase del producto en
  curso: el andamio se arregla entre fases, o cuando una fase tropieza con él.
- **Un tramo que cierra archiva su cuerpo** en `archive/TOOLING.md` y deja lápida.
- **El andamio que ningún tramo recoge** se registra `open`, como cualquier
  hueco, con el tramo que tropezaría con él o `none` y el motivo (regla dura 5
  de `../AGENTS.md`); no se cuelga del primero que quede abierto.
