# The engine of this copy of the scaffold: the version of the template it came
# from, and the files that are the template's with the sha256 of their content
# as the template shipped them (line ends folded to LF). The board reports an
# engine file that changed, an `engine` finding. A copy does not edit its
# engine: a local change is declared in exceptions.txt, with its motive, so
# that an upgrade knows what to merge by hand. In the template, the change
# that touches the engine reseals this file with `board.py seal`.
#
# A copy is upgraded by the template's tools/board/upgrade.py, run from a
# clone of the template's repository against the copy: it rewrites this file,
# so this pointer reaches every copy. Its plan says what it takes, what it
# keeps and what is left to merge by hand, and its `-h` says how to run it.
# What a copy incorporated beyond the engine (its stack layers, the pieces of
# the stack template it was created from) is recorded in components.txt,
# which the same tool keeps in step.
#
# --- KEYS ---
# version  : the version of the template (X.Y.Z), exactly once.
# engine   : '<path> <sha256>': a file of the engine; '-' until it is sealed.
# template : a path only the template has: instantiate.py does not copy it,
#            and the board asks no home for its markdown but checks its
#            citations. These rows are what tells the template from a copy:
#            instantiate.py writes a copy's manifest without them, adopt.py
#            refuses where they are and seal where they are not.
#
